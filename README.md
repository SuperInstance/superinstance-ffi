# superinstance-ffi

Unified C FFI and WASM bindings for SuperInstance math primitives. Provides `#[no_mangle] extern "C"` functions and a wasm-bindgen layer for the constraint-theory and geometry operations used across the Cocapn fleet.

## What It Does

Exports a small, focused set of math functions as a C-compatible shared library and a WASM module:

- **Eisenstein integer norm** — the fundamental metric on the Eisenstein lattice
- **Laman graph edges / rigidity** — structural rigidity counts and checks
- **Holonomy check** — verify closed-loop transforms return to identity
- **Pythagorean 48-cell encoding** — quantize 2D directions to 48 sectors
- **Manhattan distance** — L1 distance between integer vectors
- **Cascade match** — byte-level pattern matching for codebook lookups
- **Constraint checking** — count violated constraint bounds
- **Spline interpolation** — linear interpolation along polyline control points
- **Deadband filter** — suppress sub-threshold noise

## Building

### C Library

```bash
cargo build --release
```

This produces:
- `libsuperinstance_ffi.a` (static)
- `libsuperinstance_ffi.so` (shared)
- `superinstance-ffi.h` (generated by cbindgen)

### WASM Module

```bash
cd wasm
wasm-pack build --target nodejs
```

## Usage

### From C

```c
#include "superinstance-ffi.h"

// Eisenstein norm: a² - ab + b²
int64_t norm = si_eisenstein_norm(2, 3);  // 7

// Laman edges for 5 vertices: 2*5 - 3 = 7
int32_t edges = si_laman_edges(5);

// Rigidity check
bool rigid = si_is_rigid(5, 7);  // true

// Deadband: filter noise within ±0.5
double filtered = si_deadband_filter(10.3, 10.0, 0.5);  // 10.0 (within band)
double passed = si_deadband_filter(11.0, 10.0, 0.5);    // 11.0 (outside band)

// Holonomy: check if transform loop closes
int64_t transforms[] = {-1, -1, 1};
bool trivial = si_holonomy_check(transforms, 3);  // true (product = 1)

// Constraint violations
double vals[] = {1.0, 6.0, 3.0};
double bounds[] = {5.0, 5.0, 5.0};
uint8_t violated = si_constraint_check(vals, bounds, 3);  // 1
```

### From JavaScript (WASM)

```javascript
const wasm = require('./pkg/superinstance_ffi_wasm');

wasm.si_eisenstein_norm(3, 5);     // 19
wasm.si_laman_edges(12);           // 21
wasm.si_is_rigid(12, 21);          // true
wasm.si_deadband_filter(50.1, 50.0, 0.5);  // 50.0
```

## API Reference

| Function | Signature | Returns |
|----------|-----------|---------|
| `si_eisenstein_norm` | `(i32, i32) → i64` | a² - ab + b² |
| `si_laman_edges` | `(i32) → i32` | 2v - 3 |
| `si_is_rigid` | `(i32, i32) → bool` | edges ≥ 2v - 3 |
| `si_holonomy_check` | `(*i64, usize) → bool` | product == 1 |
| `si_pythagorean48_encode` | `(f64, f64) → u8` | sector in [0, 47] |
| `si_manhattan_distance` | `(*i32, *i32, usize) → i64` | Σ|xᵢ - yᵢ| |
| `si_cascade_match` | `(*u8, *u8, usize) → i32` | matching positions |
| `si_constraint_check` | `(*f64, *f64, usize) → u8` | violation count |
| `si_spline_interpolate` | `(*f64, f64, usize) → f64` | interpolated x |
| `si_deadband_filter` | `(f64, f64, f64) → f64` | val or center |
